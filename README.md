# KINGBAY V1

Project React/Vite hoàn chỉnh cho trang Home KINGBAY.

## Chạy project

```bash
npm install
npm run dev
```

Sau đó mở link Vite hiển thị trong Terminal, thường là:

```bash
http://localhost:5173
```
